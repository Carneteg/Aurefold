# RELEASE ROUTINE

1. Read `Emberwold_STATUS_NEXT_STEPS_v27_0.md`.
2. Read the relevant Lore Bible section.
3. Work from the current file only.
4. Identify conflicts before changing canon.
5. Obtain author approval for a canon change.
6. Update the Lore Bible, changelog, affected support files, and prose.
7. Build a fresh release manifest with hashes.
8. Archive older releases; do not silently merge them.
