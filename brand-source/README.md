# Brand source assets (not deployed)

High-resolution brand originals kept for reference and future use — logos, the
book cover, and social banners. These are **intentionally outside `assets/`** so
the GitHub Pages deploy (which copies only `assets/` and `data/`) does not ship
them: they are large (~13 MB total) and were not referenced by any page.

The web-sized versions the site actually uses live in `assets/brand/`
(`emblem-mark.webp`, `logo-dark.webp`).
