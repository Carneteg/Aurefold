## Hard anti-flattening rule

A recognizable social format must not replace the human being.

At least one in every three posts for a recurring character should foreground one or more of:
- private motive;
- vulnerability;
- bodily reality;
- compromise;
- error;
- cost;
- ordinary work/life;
- relationship consequence.

If audiences can predict only the joke and not the person's contradiction, the format is failing.

## Dialogue / quotation rule

Do not invent social copy and present it as a quotation from the manuscript.

Editorial characterizations such as:
- `Sela would probably begin by asking…`
- `Tomas would technically object…`
- `Alaine would notice…`

are acceptable when clearly presented as social/editorial characterization.

A quotation presented as novel text must be verified against the current governing manuscript before publication.

## Measurement

Use source keys beginning with:
- `character-sela-`
- `character-tomas-`
- `character-alaine-`
- `character-three-`

Community Manager may compare attributed entry with later Ledger / House Test / Patreon-intent activity under the existing privacy rules.

Primary character-fandom signals:
- comments naming the character rather than only the abstract dilemma;
- repeat engagement with the same character;
- readers developing recognizable affection, frustration or argument around the person;
- reading/community action after character-led discovery;
- voluntary use of character shorthand by readers.

Raw views alone are not success.
