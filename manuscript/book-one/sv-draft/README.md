## How to resume
`TRANSLATION_BRIEF.md` in this folder is the binding contract: register, per-character
voice fingerprints, the proper-noun glossary (House/character/place names stay English;
"the Bell" → "Klockan"; "Broder"/"Moder"), paragraph-exact fidelity, and the locked
final line — "She went east." must render exactly as **"Hon gick österut."**

Split the master into sections with the same numbering, translate the missing files
into this folder, then build EPUB/PDF from the assembled result.
